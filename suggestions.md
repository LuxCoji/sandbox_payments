# Suggestions & Future Ideas\n\n## UI Support for AI Red-Team Branches\n\nCurrently, the AI red-team branches are stored only in the Postgres database and are hidden from the frontend UI. In the future, we should consider fully integrating them into the visual DAG so developers can:\n- Visually audit exactly what the AI did during an attack simulation.\n- View the transaction events, state changes, and account balances generated by the agent.\n- Use the visualizer as a debugging tool to replay exploits found by the red-team agent.\n\nNote: Implementing this will require dynamically reconstructing the simulation engine from Postgres checkpoints when a red-team branch is clicked, as they do not run on the in-memory `LiveChronoDAG`.
